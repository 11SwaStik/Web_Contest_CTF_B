API Reference

The Tidepool API is organised around REST, uses resource-oriented URLs, and returns JSON for every response. Base URL:

{{ request.url_root|trim('/') }}/api/v1

Quickstart

Every request is authenticated with your API key and returns JSON. Fetch your own station account to check your setup:

curl {{ request.url_root|trim('/') }}/api/v1/accounts/me \
  -H "Authorization: Bearer {{ token }}"

Authentication

Authenticate with a bearer token in the Authorization header. Use your sandbox test key below while developing:

Test API key{{ token }}
Account id{{ account_id }}

Requests without a valid key return 401.

Errors

Tidepool uses conventional HTTP status codes. Errors return a JSON body with an error code and a human-readable message.

{
  "error": "unauthorized",
  "message": "Provide a valid 'Authorization: Bearer <token>' header."
}
200OK
401Missing or invalid API key
404Resource not found

API reference

GET /v1/accounts/me

Returns the account associated with your key.

curl {{ request.url_root|trim('/') }}/api/v1/accounts/me \
  -H "Authorization: Bearer {{ token }}"

Returns id, owner_name, email, plan, private_note.

PATCH /v1/accounts/me

Updates your account profile. Send any subset of the editable fields as a JSON body.

owner_namestring — display name on the account.
emailstring — contact email.
curl -X PATCH {{ request.url_root|trim('/') }}/api/v1/accounts/me \
  -H "Authorization: Bearer {{ token }}" \
  -H "Content-Type: application/json" \
  -d '{"owner_name": "New Name"}'

Returns the updated account, same shape as GET /v1/accounts/me.

GET /v1/usage

Returns request usage and limits for the current billing period.

curl {{ request.url_root|trim('/') }}/api/v1/usage \
  -H "Authorization: Bearer {{ token }}"

GET /v1/events

Lists recent events for your account (most recent first).

curl {{ request.url_root|trim('/') }}/api/v1/events \
  -H "Authorization: Bearer {{ token }}"

GET /v1/health

Returns API status. No authentication required.

curl {{ request.url_root|trim('/') }}/api/v1/health
